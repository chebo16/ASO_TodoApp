# TodoApp — ASP.NET Core 8

Aplicație simplă de tip TODO realizată folosind ASP.NET Core.

Proiectul include:

- ASP.NET Core 8 Web API
- Entity Framework Core
- SQLite
- Swagger
- Interfață web simplă în HTML, CSS și JavaScript

---

## Structura proiectului

```text
ASO_TodoApp:
1)Controllers
  TodosController.cs
2)Data
  AppDbContext.cs
3)Models
  TodoItem.cs
4)wwwroot
  index.html
5)Program.cs
6)README.md
7)TodoApp.csproj
8)appsettings.json
```
